# Cybersecurity Portfolio

This repository contains a selection of penetration testing reports and cybersecurity labs completed through platforms such as **TryHackMe** and **Hack The Box**.

The exercises cover different areas of offensive security, including **network enumeration, web application security, Active Directory, credential attacks, exploitation, post-exploitation and privilege escalation** in Windows and Linux environments.

The reports document the methodology followed, the vulnerabilities identified, the exploitation process and the resulting impact within authorized laboratory environments.

> **Note:** The practical work and security assessments were performed by me. The reports were prepared with the assistance of an **AI Penetration Testing Reporting Copilot**, which was used to help structure, document and present the findings in a professional format.
